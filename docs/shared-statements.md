# Shared statements and translation review

`common_statement` precedes every language's legend. `common_tutorial`
precedes every editorial and remains excluded from participant statements
and default printing. Language-specific fields remain separate in Editor
snapshots; rendered documents and ZOJ exports contain the effective text.

Choose `translation_source` to track an original language. A human review
stamp binds both the current source (including common sections) and target
content hashes. Source changes mark translations stale; editing a reviewed
translation marks it modified. Toggling print visibility does not change
content freshness. This records human review, not automatic translation
quality. Translators cannot modify common content or the chosen original.
