# 스트레스 테스트 탐색과 반례 보강

## 생성 패턴과 재현

생성기 명령의 `[a..b]`는 양 끝을 포함한 64비트 정수 범위입니다.
반복마다 범위별 정수를 뽑아 실제 인자로 바꾼 뒤 생성기를 실행합니다.

```text
gen [1..10] [50..100] {seed}
gen --mode negative --n=[1..50] {seed}
```

`{seed}`를 생략하면 마지막 인자로 시드를 추가합니다. 시작 시드와 증가량을
설정할 수 있습니다. 여러 패턴은 입력 하나를 생성할 때마다 순환합니다.
같은 패턴 순서, 샘플링 버전, 시드를 사용하면 같은 범위 인자를 얻습니다.
생성기가 자체 시드를 무시하거나 외부 정보를 사용하면 입력까지 같다는 보장은
없으므로, 작업 기록은 실제 명령과 발견한 입력 원본도 함께 보관합니다.

범위 추첨은 Python 프로세스의 전역 난수 상태를 사용하지 않습니다.
`sha256-range-v1`은 시드·패턴 인덱스·범위 위치를 사용하고, 편향 없는
거절 표본 추출로 정수를 정합니다. 명령은 셸에서 실행하지 않습니다.

UI의 조합 도구에서는 `mode`, `N`, 값 하한·상한을 정하고 생성기가 받는
순서에 맞춰 `{mode} {N} {lo} {hi} {seed}` 템플릿을 작성합니다.
mode마다 패턴 하나가 만들어지고 N은 범위에서 뽑힙니다. 생성기의 모드나
분포 구현 자체를 변경하거나 새로 만들어 주는 기능은 아닙니다.

## 종료 조건과 집중 검사

- 첫 반례: 해당 입력의 모든 선택 풀이를 비교한 뒤 끝냅니다.
- 목표 개수: 서로 다른 반례 입력을 지정 개수까지 모읍니다.
- 모든 비교 풀이: 각 풀이에서 수집 대상 판정이 최소 한 번씩 나올 때까지
  실행합니다. 반례가 확인된 풀이는 다음 입력부터 제외합니다.
- 미검출 집중: 목표 개수 모드에서도 이미 검출한 풀이를 제외할 수 있습니다.

모든 모드에 반복·시간·작업 전체 실행 한도가 적용됩니다. 한도에 먼저 닿으면
미검출 풀이를 명시합니다. 결과의 재실행 버튼은 그 풀이만 선택하고 마지막
기록 시드 다음부터 새 작업을 만듭니다. 원래 판정 태그와 문제 파일은 바꾸지
않습니다. 같은 입력은 한 작업에서 다시 비교하지 않습니다.

## 자동 축소

자동 축소는 선택 기능이며 비인터랙티브 문제에서 지원합니다. 발견한 원본은
유지하고 축소본을 별도로 보관합니다.

1. `N` 뒤에 정확히 `N`개의 정수가 오는 한 줄·배열 한 줄·원소별 줄바꿈
   형식을 인식하면 배열 구간을 지우고 N도 함께 줄입니다.
2. 정수 값을 0, 절댓값 1, 절반 등 더 작은 절댓값 후보로 줄여 봅니다.
   다른 텍스트 입력은 공백과 줄바꿈을 보존하며 정수 값만 줄여 봅니다.
3. 각 후보를 같은 세트·그룹의 Validator와 기준 풀이로 실행합니다.
4. 원래 실패한 모든 풀이를 재실행하고, 같은 판정이 모두 유지된 후보만
   채택합니다. TLE·MLE는 같은 후보에서 두 번 연속 재현되어야 합니다.
5. 채택한 축소 입력·기준 출력·실제 출력과 판정을 별도로 저장합니다.

반례별 시도·시간 한도와 작업 전체 한도가 적용됩니다. 입력 크기 한도는
환경 조회 API에서 제공합니다. 축소 예산·지원 형식·중단 여부는 기록에
표시하며, 모든 가능한 입력 중 수학적 최소를 증명했다고 표시하지 않습니다.
Validator·Checker·testlib 및 원본 풀이를 수정하지 않습니다.

## 분류, 발견률과 커버 선택

풀이 이름과 실제 관측 판정으로 반례를 분류합니다. 서로 같은 논리적 원인인지
추정하지 않습니다. 패턴별 발견률은 실제 비교한 고유 입력 중 반례 입력의
비율입니다. 중복·미비교 입력은 분모에서 제외합니다. 집중 검사에서는
패턴마다 비교 대상이 달라질 수 있습니다.

커버의 대상은 관측한 `(풀이, 판정)` 조합입니다. 16개 이하 반례는 전체
조합을 확인해 이를 모두 유지하는 가장 적은 개수를 선택합니다. 더 많으면
탐욕 선택과 중복 제거를 사용하며, 화면에도 근사 선택임을 표시합니다.
실행하지 않은 풀이·입력 조합이 통과하거나 실패했다고 간주하지 않습니다.

## 테스트 그룹에 등록

실행 전에 Validator에 전달할 세트·그룹을 선택할 수 있습니다. 등록할 때
그룹을 바꾸거나, 원본과 검증된 축소본 중 사용할 입력을 선택할 수도 있습니다.
실행 당시와 다른 세트·그룹이면 등록 후 입력·정답 생성을 통해 그 문맥의
Validator를 다시 실행해야 합니다. 같은 입력은 중복 추가하지 않습니다.

반례 추가는 쓰기 권한에서만 가능하며 작업 사본에 저장합니다. 검수자는
커밋된 자료로 실행·결과 열람은 가능하지만 문제 자료에 직접 반영할 수
없습니다. 문제 자료가 바뀐 뒤 오래된 결과를 그대로 반영하는 것도 차단합니다.
