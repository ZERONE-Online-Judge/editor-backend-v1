# 파일 분류와 컴파일 리소스

Source는 generator·validator·checker 등 실행 소스, Resource는 컴파일에
첨부할 파일, Aux는 제작 보조 자료, Solution은 검증할 풀이입니다.

Resource는 적용 언어를 선택하고 대상 Solution·단계 Compile로 제한할 수
있습니다. 해당 언어의 풀이를 컴파일할 때만 첨부하며 Validator·Checker 등
다른 프로그램에는 제공하지 않습니다. 컴파일 전용 원본 파일은 실행 산출물에
복사하지 않습니다. grader 소스나 정적 라이브러리(.a/.o)는 '풀이와 함께
컴파일'도 선택하면 C/C++ 링크 명령에 포함합니다. 정적 바이너리는 대상
런타임과 ABI가 맞아야 하며, 맞지 않으면 컴파일 오류로 보고합니다.

현재 조건부 정책은 Compile·Solution만 지원합니다. 실행 시 파일이 필요한
런타임 리소스나 다른 대상의 조건부 첨부를 지원한다고 표시하지 않습니다.
정책이 없는 Resource는 기존과 같이 모든 프로그램의 컴파일에 첨부합니다.

새 Aux는 기본적으로 첨부하지 않습니다. 예전 Aux는 기존 자동 첨부를 유지하며
편집 창의 '기존 호환' 옵션을 끄면 제작 자료로만 보관합니다.

Editor의 격리 실행은 이 정책을 적용합니다. 실행 전송이 agent이면 동일한
정책으로 파일을 선별한 뒤 기존 채점 노드의 격리 실행에 보냅니다. 별도의
ZOJ 최종 채점 프로토콜과 ZOJ 문제 ZIP은 이 컴파일 정책을 표현하지 못하므로
호환성 오류를 안내합니다. 정책을 무시한 검증이나 내보내기는 하지 않습니다.
