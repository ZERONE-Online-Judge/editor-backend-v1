# 재현용 Linux 패키지

패키지 형식에서 Linux를 선택하면 ZOJ 실제 채점기로 전체 테스트와 풀이를
검증하고, 다음을 함께 내보냅니다. 검증 없이 내보내기도 지원하지만 해당
패키지는 검증 완료로 표시하지 않습니다.

- 모든 생성 입력·기대 출력과 SHA-256 blob
- 지문·공용 라이브러리·소스·풀이·Validator·Checker
- 그룹별 기대 판정과 컴파일 리소스 정책
- 원래 실행 결과와 실제 CPU·아키텍처·컴파일러 버전
- 해당 릴리스의 고정된 Sandbox 엔진과 표준 라이브러리 전용 실행기
- 런타임 Dockerfile·감독 코드·네이티브 실행기와 SHA256SUMS

압축을 풀고 `python3 replay/replay.py --image IMAGE_ID`를 실행합니다.
Python 3.10 이상과 Docker, 준비된 런타임 이미지만 필요합니다. API 키,
서비스 DB, Python 외부 패키지는 사용하지 않습니다. 프로그램 실행은
네트워크가 없는 Docker 격리 환경에서 이루어집니다.

이미지를 준비한 뒤 docker save/load로 옮기면 오프라인에서도 실행됩니다.
재현 명령이 이미지를 자동으로 빌드하거나 다운로드하지 않습니다. 원래 이미지
ID가 있으면 이를 기본으로 사용하며, 없으면 명시적으로 이미지를 지정합니다.
빌드 레시피의 apt 패키지 버전은 고정되지 않으므로 같은 환경이 필요하면
원래 이미지 ID와 이미지 아카이브를 사용해야 합니다.

실행 결과는 replay-result.json에 저장합니다. 언어별 컴파일·Java 힙·CPU
시간·메모리·리소스 조건과 범위 기대 판정은 내보낸 Editor 엔진을 사용합니다.
언어별 자동 보정·직접 지정·보정 끄기는 저장된 정책대로 숫자로 적용합니다.
오프라인 엔진과 ZOJ의 런타임은 서로 다르며, 동일한 시간·메모리 측정값을
재현한다고 표시하지 않습니다. 이미지가 같아도 CPU·가상화·부하에 따라 시간은
달라지므로 준비·검증·재현 환경 기록을 함께 비교해야 합니다.
