# 풀이의 범위별 기대 판정

풀이의 기본 태그는 기존과 같이 보관합니다. `extra_tags`는 테스트 세트별
기대 판정이며, `group_tags[테스트 세트][그룹]`으로 그룹 기대 판정을 지정합니다.
같은 이름의 그룹이 서로 다른 세트에 있어도 구분합니다. 기존의 세트·그룹
추가 태그는 읽을 수 있지만 모호한 그룹 이름을 새로 저장할 수는 없습니다.

그룹 지정 → 세트 지정 → 기본 기대 판정 순서로 적용합니다. 그룹을 별도로
지정하면 그 그룹의 테스트는 기본 범위에서 제외됩니다. 예를 들어 기본 TL,
small=OK, large=TL이면 small의 모든 테스트는 AC여야 하고 large에서는
TLE가 적어도 한 번 관측되어야 합니다. 기본 NR은 풀이 전체 실행 제외이며,
이 경우 범위별 예외 설정은 적용하지 않습니다.

범위 NR은 그 범위의 풀이 검증을 건너뜁니다. Main을 사용한 정답 생성과
Validator 검사는 별도 준비 단계이므로 그대로 수행합니다. 환경 오류와
컴파일 오류를 기대 판정 일치로 취급하지 않습니다.

일부 테스트 번호만 실행하면 나머지는 미확인입니다. 전체 범위를 실행하지
않고 전체 기대 판정을 검증 완료했다고 표시하지 않습니다. 서로 다른 범위의
결과, 실행 개수와 전체 개수는 서버 실행 기록에 함께 보관됩니다.

Editor ZIP의 editor.json은 모든 설정을 보존합니다. Editor가 만드는 XML에는
ZOJ 네임스페이스 확장으로도 기대 판정을 보관합니다. 이 확장을 외부 Polygon
서버가 해석한다고 가정하지 않습니다.
