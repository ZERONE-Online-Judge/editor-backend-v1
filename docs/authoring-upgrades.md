# 제작·검수 기능 확장

기존 문제 스냅샷의 기본값·해시는 유지하고 새 설정을 선택한 자료에만
필드를 추가합니다. 프런트엔드와 백엔드는 다음 기능 브랜치로 나누어
차례로 개발했습니다. 뒤 브랜치는 앞 브랜치의 변경을 포함합니다.

| 브랜치 | 화면과 변경 |
| --- | --- |
| `feature/scoped-expectations` | 풀이 편집의 세트·그룹별 기대 판정 |
| `feature/generator-loops` | 등록 테스트의 시드 반복 생성 도구와 `repeat` 문법 |
| `feature/test-verdict-matrix` | 실행 결과의 판정·시간·메모리와 검출력 매트릭스 |
| `feature/statement-samples` | 테스트 편집의 지문 표시용 입출력과 별도 검증 |
| `feature/resource-policies` | 파일 분류와 언어별 Solution 컴파일 첨부 정책 |
| `feature/linux-replay-package` | 패키지의 Linux 재현 형식과 오프라인 실행기 |
| `feature/bulk-test-operations` | 등록 테스트 선택·일괄 작업과 부분 재생성 |
| `feature/shared-statements` | 지문의 공통 설명·해설과 번역 검토 상태 |
| `feature/structured-review` | 개요의 분류별 검수 보고서와 실행 근거 링크 |

## 주요 사용 흐름

1. 풀이의 기본 판정과 세트·그룹별 재정의를 저장합니다.
2. 등록 테스트에서 반복 생성 규칙 또는 선택 행의 일괄 작업을 적용합니다.
3. 입력·정답 생성을 실행하고 결과를 반영합니다. 부분 생성은 살아 있는
   스크립트를 먼저 전체 생성·반영한 뒤 사용합니다.
4. 필요한 범위의 풀이 검증을 실행합니다. 실행 결과에서 매트릭스를
   확인하며 부분 실행과 미실행은 전체 통과로 표시하지 않습니다.
5. 개요의 검수 보고서에서 저장된 자료와 대응 실행 기록을 확인합니다.
6. 커밋한 뒤 Linux 패키지를 내보내고 준비된 Docker 이미지로 재실행합니다.

## 지원 범위

- 반복 문법은 제한된 자체 DSL이며 FreeMarker 전체 문법이 아닙니다.
- Resource 정책은 현재 Solution의 Compile 단계만 지원합니다.
- 등록 테스트 최소 커버는 관측한 오답을 기준으로 합니다. 작은 집합은
  정확한 최소, 큰 집합은 근사이며 미검출 풀이를 숨기지 않습니다.
- 표시용 입출력은 선택 시 Validator·Main·Checker로 따로 검증합니다.
  인터랙티브 대화 예제는 자동 정답 검증 대신 명시적인 수동 검토가 필요합니다.
- Linux 패키지는 생성 자료와 엔진 소스를 포함합니다. Docker 이미지 자체는
  별도로 준비해야 하며 하드웨어 성능까지 동일함을 보장하지 않습니다.
- 검수 보고서는 규칙과 저장된 실행 근거를 사용합니다. 제한 비교는 명시적
  숫자 범위만 인식하며 자동 의미 증명이나 AI 문장 교정은 수행하지 않습니다.
- 공통 해설은 검수용 해설로 유지하며 참가자 지문과 기본 인쇄에 노출하지
  않습니다. 번역 검토 표시는 원문과 번역문 두 해시로 갱신 여부를 추적합니다.

자세한 정책은 이 디렉터리의 각 기능 문서를 참고하세요.
