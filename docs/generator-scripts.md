# 반복 생성 스크립트

```text
repeat seed in 1..100
  group random-small
  gen 10 {seed} > $
end
```

양 끝을 포함합니다. `step 2` 또는 `step -1`을 지정할 수 있습니다.
중첩 반복은 최대 4단계이며 선언한 변수만 `{변수}`로 치환됩니다.
임의 표현식, FreeMarker, 셸 명령은 실행하지 않습니다.
`> $`는 수동 테스트가 사용하지 않는 다음 번호를 고릅니다.
`> {seed}`처럼 번호를 직접 지정할 수도 있으며 중복 번호는 거부합니다.

`group 이름`은 같은 블록의 이후 명령에 적용하고 `group -`로 해제합니다.
블록 내부의 그룹 변경은 바깥 블록에 영향을 주지 않습니다. 그룹은 현재
테스트 세트에 미리 등록하고 그룹 사용을 켜야 합니다. 확장 결과는 기존과
같이 세트당 최대 1,000개이며 계산 단계도 20,000단계로 제한합니다.

UI의 시드 범위 도구는 규칙을 스크립트에 추가합니다. 실제 생성·Validator
검사·Main 출력 생성은 입력·정답 생성 버튼을 눌러야 시작합니다.
