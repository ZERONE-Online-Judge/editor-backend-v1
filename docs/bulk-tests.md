# 등록 테스트 일괄 작업

행 선택 또는 전체 선택으로 그룹·설명·예제 여부를 변경하고, 테스트를 제거하거나
다른 세트로 복사·이동할 수 있습니다. 전체 번호 정렬은 현재 순서를 유지하며
1부터 번호를 다시 붙입니다. 저장된 리비전·이전 실행 결과는 바꾸지 않습니다.

일괄 작업은 먼저 모든 조건을 확인한 사본을 만들고 한 번에 작업 사본에
반영합니다. 잘못된 그룹, 대상 세트 용량 초과, 중복 입력 정책 위반 등이 있으면
부분 이동이나 삭제를 하지 않습니다. 쓰기 권한과 기존 작업 사본 버전·충돌
정책을 그대로 적용합니다. 생성 스크립트가 남아 있으면 전체 생성 결과를
먼저 반영한 뒤 등록 테스트를 다룹니다.

선택 번호로 다음 준비 작업을 실행할 수도 있습니다.

- 전체 준비: 선택 입력을 생성하고 Validator·Main·Checker를 실행
- 입력만: 생성기와 Validator만 실행, 입력이 달라지면 기존 정답을 비움
- Validator 검사: 저장된 입력만 검사, 생성기·Main·Checker를 실행하지 않음
- 정답만: 저장된 입력을 Validator로 확인하고 Main 정답을 재생성

부분 결과를 반영할 때 선택하지 않은 테스트는 유지합니다. 직접 입력은 생성기로
바꾸지 않습니다. 작업 기록은 준비 모드와 선택 번호를 보관하며, 실행하지 않은
단계가 완료됐다고 표시하지 않습니다. 입력만·Validator 검사에는 Main이 없어도
됩니다. 번호·내용이 변경된 후 과거 결과를 자동 반영하는 것은 기존처럼 차단합니다.
