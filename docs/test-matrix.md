# 테스트 판정 매트릭스

실제 저장된 개별 테스트 판정으로만 비교합니다. 아직 실행하지 않은 칸은
미실행이며, 범위별 NR은 제외로 표시합니다. ZOJ 배치 채점이 개별 테스트
자원 측정치를 반환하지 않으면 시간·메모리를 추정해 채우지 않습니다.

검출 대상은 그 테스트 범위에서 WA·TL·ML·RE·PE·RJ·TM으로 지정한 풀이입니다.
실제 WA·TLE·MLE·RE 등 실패 판정이 관측되면 검출로 셉니다. 컴파일·환경
오류는 반례 검출로 취급하지 않습니다. 기대 판정 일치 여부는 별도 범위
검증 결과에서 확인합니다.

동일 패턴은 모든 선택 풀이의 판정 벡터가 같고 미확인 칸이 없는 경우입니다.
같은 원인, 같은 입력, 불필요한 테스트라는 뜻은 아닙니다. 제거 영향은
현재 관측된 검출을 기준으로 해당 테스트에서만 잡힌 풀이를 표시합니다.

커버는 현재 검출한 풀이들을 모두 잡는 테스트 선택입니다. 16개 이하
반례 테스트는 정확한 최소 개수, 그 이상은 탐욕적 근사 선택입니다.
검출하지 못한 풀이 목록은 따로 보존하며, 이들까지 검증했다고 표시하지
않습니다. 커버 필터를 적용해도 테스트를 수정하거나 삭제하지 않습니다.

새 결과는 분석을 함께 저장합니다. 이전 실행 기록은 보존된 문서와 결과로
조회 시 분석하며, 현재 작업 사본 설정으로 과거 판정을 바꾸지 않습니다.
