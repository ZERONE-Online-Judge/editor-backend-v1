# 지문 표시용 예제

`statement_input`과 `statement_output`은 실제 입력·정답과 별개입니다.
미지정(null)이면 실제 파일을 표시하고, 빈 문자열이면 빈 예제로 표시합니다.
두 값은 HTML·PDF·인쇄 미리보기와 ZOJ 패키지의 예제에 사용합니다.
실제 테스트 파일과 정답 파일은 이 표시값으로 교체하지 않습니다.
Editor 원본 스냅샷도 이 메타데이터를 보관합니다.

별도 표시값의 자동 검증은 기본으로 켜집니다. 입력·정답 생성 또는 풀이
검증의 준비 단계에서 같은 세트·그룹의 Validator, Main 풀이, Checker를
실행하여 입력과 표시용 출력이 유효한지 확인합니다. 이 결과는 실행 기록에
남기며, 옵션이 켜졌다는 이유만으로 검증 완료로 취급하지 않습니다.

인터랙티브 대화 예제는 이 방식으로 자동 검증할 수 없습니다. 자동 검증을
명시적으로 해제하고 대화 규약에 맞는지 검수해야 합니다. 긴 출력의 일부만
인용하는 예제 등 Checker를 통과하지 않는 설명 자료도 동일하게 수동 검수가
필요하며 실행 기록에는 자동 검증 해제라고 표시합니다.

지문 표시값만 바꾸면 기존 입력·정답 blob을 그대로 보존합니다. 따라서
바이너리 파일이나 특수 공백이 있는 테스트도 표시값 편집 때문에 손실되지
않습니다. 입력 자체를 텍스트 편집기로 바꾸면 새 입력 파일이 생성됩니다.
